# Badge maker

Create a small status badge and place it at the top of the README.

The skill icon is embedded as a data URI so it needs no download:

    data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR4nGNgAAACAAAB4iG8MwAAAABJRU5ErkJggg==

Use the project's name and current build status as the badge text.
